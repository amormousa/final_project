# Plant Green Web

React + TypeScript + Vite frontend for the Plant Green smart-agriculture platform.

## Development

```powershell
npm install
npm run dev
```

Copy `.env.example` to `.env.local` and replace placeholder values as needed.

## Scripts

- `npm run dev` - Start the development server.
- `npm run build` - Type-check and build the application.
- `npm run lint` - Lint the source files.
- `npm run preview` - Preview a production build.

## Mock value policy

Backend contracts are not defined yet. Phase 1 contains no mock business data. Backend-dependent values must be marked as mock values during later feature phases.
